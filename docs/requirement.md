# Requirement Summary

## Scenario
ออกแบบระบบสรรหาบุคลากรที่ขับเคลื่อนด้วย AI สำหรับ Remuse โดยมี resume มากกว่า 100 ฉบับ สำหรับตำแหน่ง Full-Stack / AI Engineer

## Must-have
- 1-3 years production web development
- JavaScript / TypeScript
- real AI / LLM hands-on experience
- frontend, backend, API, database
- Git and teamwork
- Thai native / near-native
- working English
- portfolio or repository with real work

## Nice-to-have
- backend platform / modern database
- AI workflow / logic
- video-related products
- HR tech / marketplace

## What the system must explain
1. What is a hard filter vs soft matching
2. What information AI extracts from CV
3. How relevant experience is interpreted beyond keyword matching
4. How candidates are ranked/grouped for recruiter review
5. What evidence supports each recommendation
6. How missing/unclear information is handled
7. What additional data should come from candidate/company
8. AI boundaries, fairness, and recruiter decision ownership

## Deliverables
- Working prototype
- Screening logic / rationale
- Additional data proposal
- AI philosophy and analysis boundaries
